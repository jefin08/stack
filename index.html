Python + Django Full-Stack Guide

The simplest path: Python + Django + HTML/CSS + JavaScript + SQLite without unnecessary complexity. One complete project from zero, step by step.

Step 1

Setup Environment

Check Python installation, create project folder, set up virtual environment, and install Django:

powershell / bash 
# 1. Check Python installation
python --version

# 2. Create project folder
mkdir django_project
cd django_project

# 3. Create virtual environment
python -m venv venv

# 4. Activate it on Windows
venv\Scripts\activate

# 5. Install Django
pip install django

# 6. Check Django version
django-admin --version
Step 2

Create Django Project

Initialize the project inside the current directory (note the trailing period .):

powershell 
django-admin startproject config .

You will get the following structure:

directory tree 
django_project/
│
├── config/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py
│
├── manage.py
└── venv/

Start the development server:

powershell 
python manage.py runserver
💡 Open your browser at: http://127.0.0.1:8000/ to verify the rocket animation!

Step 6

Create Student Model

Open students/models.py and add the Student model:

python — students/models.py 
from django.db import models


class Student(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
    course = models.CharField(max_length=100)
    age = models.IntegerField()

    def __str__(self):
        return self.name

Step 10

Create Forms (ModelForm Shortcut)

Create students/forms.py using Django's ModelForm:

python — students/forms.py 
from django.forms import ModelForm

Django automatically maps all fields: Name, Email, Course, Age.

Step 11

Create Views (Generic Class-Based Views)

Open students/views.py. We use Django's Generic Views to keep the code concise and clean:

python — students/views.py 
from django.urls import reverse_lazy
from django.views.generic import ListView, CreateView, UpdateView, DeleteView

from .models import Student


class StudentList(ListView):
    model = Student
    template_name = 'students/student_list.html'
    context_object_name = 'students'


class StudentCreate(CreateView):
    model = Student
    fields = '__all__'
    template_name = 'students/student_form.html'
    success_url = reverse_lazy('student_list')


class StudentUpdate(UpdateView):
    model = Student
    fields = '__all__'
    template_name = 'students/student_form.html'
    success_url = reverse_lazy('student_list')


class StudentDelete(DeleteView):
    model = Student
    template_name = 'students/student_delete.html'
    success_url = reverse_lazy('student_list')

Normal Django way

Model → ModelForm → Function View

Short way (Used here)

Model → Generic View (fields = '__all__')
Step 12

Create App URLs

Create students/urls.py to define routes for list, add, edit, and delete actions:

python — students/urls.py 
from django.urls import path
from .views import (
    StudentList,
    StudentCreate,
    StudentUpdate,
    StudentDelete
)


urlpatterns = [
    path('', StudentList.as_view(), name='student_list'),
    path('add/', StudentCreate.as_view(), name='student_add'),
    path('edit/<int:pk>/', StudentUpdate.as_view(), name='student_edit'),
    path('delete/<int:pk>/', StudentDelete.as_view(), name='student_delete'),
]

docs / Architecture_Flow.txt 
DJANGO ARCHITECTURE FLOW (MTV - MODEL TEMPLATE VIEW):

1. User sends HTTP Request from Browser:
   http://127.0.0.1:8000/

2. URL Dispatcher (config/urls.py & students/urls.py):
   Matches URL pattern and invokes the corresponding View class or function.

3. View (students/views.py):
   Executes application logic.
   Communicates with Model to query or mutate database records.

4. Model (students/models.py):
   Interacts with SQLite database (db.sqlite3) via Django ORM.
   Returns querysets or object instances.

5. Template (students/templates/students/*.html):
   Django Template Language (DTL) renders variables, loops ({% for %}),
   and form controls into pure HTML.

6. Browser:
   Receives rendered HTML page with CSS and JavaScript response.
manage.py 
#!/usr/bin/env python
"""Django's command-line utility for administrative tasks."""
import os
import sys


def main():
    """Run administrative tasks."""
    os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'config.settings')
    try:
        from django.core.management import execute_from_command_line
    except ImportError as exc:
        raise ImportError(
            "Couldn't import Django. Are you sure it's installed and "
            "available on your PYTHONPATH environment variable? Did you "
            "forget to activate a virtual environment?"
        ) from exc
    execute_from_command_line(sys.argv)


if __name__ == '__main__':
    main()

from django.contrib import messages
from django.contrib.auth.decorators import login_required, user_passes_test

from .models import student

# Create your views here.
def teacher_login(request):
    if request.method == 'POST':
        user = authenticate(request, username=request.POST['username'], password = request.POST['password'])

        if user and user.is_staff:
            login(request,user)
            return redirect('student_list')
        messages.error(request,'Invalid')

    return render(request,'login.html')

@login_required
def teacher_logout(request):
    logout(request)
    return redirect('login')

@login_required
def student_list(request):
    students = student.objects.all()
    return render(request, 'student_list.html',{'students':students})

@login_required
def add_student(request):
    form = studentForm(request.POST or None)
    if form.is_valid():
        form.save()
        return redirect('student_list')
    return render(request,'student_form.html',{'form':form, 'title':'add student'})

@login_required
def edit_student(request, id):
    student_obj = get_object_or_404(student, id=id)
    form = studentForm(request.POST or None, instance=student_obj)
    if form.is_valid():
        form.save()
        return redirect('student_list')
    return render(request, 'student_form.html', {'form': form, 'title':'edit student'})


@login_required
def delete_student(request, id):
    student_obj = get_object_or_404(student, id=id)
    if request.method == 'POST':
        student_obj.delete()
